# 스펙 계산기 

## 1. 유저 입력 필드

### 1-1. 장비 입력
- 무기 위력
- 무기 무게
- 무기 속성
- 방어구 위력
- 방어구 무게
- 방어구 속성
- 장신구 위력
- 장신구 무게
- 장신구 속성

### 1-2. 캐릭터 및 환경 입력
- 캐릭터 속성
- 마을 속성

### 1-4. 상대 스펙 입력
- 상대 방어력
- 상대 마법방어력

### 1-3. 캐릭터 스탯 입력
- 힘
- 생명
- 정신
- 지능
- 행운
- 속도

## 2. 유저 입력 필드 (해방 옵션)

### 2-1. 스탯 해방 옵션
- 힘 + n.n%
- 생명 + n.n%
- 정신 + n.n%
- 지능 + n.n%
- 행운 + n.n%
- 속도 + n.n%

### 2-2. 장비 위력 해방 옵션
- 무기 위력 + n.n%
- 방어구 위력 + n.n%
- 장신구 위력 + n.n%

### 2-3. 관통 해방 옵션
- 방어력 관통 + n.n%
- 마법방어력 관통 + n.n%

### 2-4. 어빌리티 옵션 (표기값 계산 후 곱연산)
- 공격력 어빌리티 + n.n%
- 마법공격력 어빌리티 + n.n%
- 회피치 어빌리티 + n.n%
- 적중치 어빌리티 + n.n%
- 치명타 확률 어빌리티 + n.n%
- 치명타 데미지 어빌리티 + n.n%

---

## 3. 속성 보정 규칙 (공통 모듈)

### 3-1. 장비 속성 보정
- 장비 속성 = 캐릭터 속성 → 1.2
- 장비 속성 ≠ 캐릭터 속성 → 1.0

### 3-2. 마을 속성 보정

#### 1) 일치
- 캐릭터 속성 = 마을 속성 → 1.1

#### 2) 불일치 (상성 판정)
상성 관계:  
불 < 물 < 번개 < 별 < 바람 < 불  
빛 < 어둠 < 빛

보정값:  
- 상성에서 약한 경우 → 0.9  
- 관련 없음 → 1.0  
- 빛 ↔ 어둠 → 0.9

#### 3) 예시
- 캐릭터 물 / 마을 번개 → 0.9  
- 캐릭터 어둠 / 마을 빛 → 0.9

## 4. 결과 항목

### 4-1. 공격력

#### ■ 공식
표기값 = {  
  [ (무기 위력 × (1 + 무기 위력 해방옵션%)) × 장비 속성 보정 ]  
  +  
  [ (힘 × (1 + 힘 해방옵션%)) ]  
} × 마을 속성 보정
최종값 = 표기값 × (1 + 공격력 어빌리티%)

---

### 4-2. 마법공격력

#### ■ 공식
표기값 = {  
  [ (무기 위력 × (1 + 무기 위력 해방옵션%)) × 장비 속성 보정 ]  
  +  
  [ (지능 × (1 + 지능 해방옵션%)) ]  
} × 마을 속성 보정
최종값 = 표기값 × (1 + 마법공격력 어빌리티%)

---

### 4-3. 방어력

#### ■ 공식
방어력 = {  
  [ (방어구 위력 × (1 + 방어구 위력 해방옵션%)) × 장비 속성 보정 ]  
  +  
  [ (장신구 위력 × (1 + 장신구 위력 해방옵션%)) × 장비 속성 보정 ]  
  +  
  [ (생명 × (1 + 생명 해방옵션%)) ]  
} × 마을 속성 보정

---

### 4-4. 마법방어력

#### ■ 공식
마법방어력 = {  
  [ (장신구 위력 × 4.5 × (1 + 장신구 위력 해방옵션%)) × 장비 속성 보정 ]  
  +  
  [ (정신 × (1 + 정신 해방옵션%)) ]  
} × 마을 속성 보정

---

### 4-5. 공격속도

#### ■ 공식
공격속도 =  
  (속도 × (1 + 속도 해방옵션%))  
  − 무기 무게  
  − 방어구 무게  
  − 장신구 무게

---

### 4-6. 회피치

#### ■ 공식
표기값 =  
  [ 지능 × (1 + 지능 해방옵션%) × 3.5 ]  
  +  
  [ 행운 × (1 + 행운 해방옵션%) × 2 ]  
  +  
  [ 공격속도 × 2 ]
최종값 = 표기값 × (1 + 회피치 어빌리티%)

---

### 4-7. 적중치

#### ■ 공식
표기값 =  
  [ 정신 × (1 + 정신 해방옵션%) × 2.8 ]  
  +  
  [ 행운 × (1 + 행운 해방옵션%) × 1.6 ]  
  +  
  [ 공격속도 × 1.6 ]
최종값 = 표기값 × (1 + 적중치 어빌리티%)

---

### 4-8. 치명타 확률

#### ■ 공식
표기값 =  
  [ 행운 × (1 + 행운 해방옵션%) × 0.0535 ]  
  + 0.45
최종값 = 표기값 × (1 + 치명타 확률 어빌리티%)

---

### 4-9. 치명타 데미지(%)

#### ■ 공식 // JS: Math.ceil()
표기값 =  
  103  
  + CEIL(  
    ( 2.0 × [힘 × (1 + 힘 해방옵션%)]  
    + 0.9 × [행운 × (1 + 행운 해방옵션%)] )  
    / 34  
  )
최종값 = 표기값 × (1 + 치명타 데미지 어빌리티%)

---

### 4-10. 회복력

#### ■ 공식 
현재 알 수 없음.
"공식 알 수 없음" 으로 출력.

## 5. 관통 매커니즘

### 5-1. 방어력 관통

#### ■ 매커니즘
- 방어력 관통 해방 옵션의 n.n%만큼 상대 방어력의 일정 비율을 계산하여 별도 항목으로 표시
- 방어력 관통 보너스 = 상대 방어력 × (방어력 관통 해방 옵션% / 100)
- **공격력에 합산되지 않으며, 별도 항목으로 표시됨**

#### ■ 예시
- 상대 방어력: 1000
- 방어력 관통 해방 옵션: 5.0%
- 방어력 관통 보너스 = 1000 × (5.0 / 100) = 50
- 공격력: 500 (별도 표시)
- 방어력 관통 보너스: +50 (별도 표시)

---

### 5-2. 마법방어력 관통

#### ■ 매커니즘
- 마법방어력 관통 해방 옵션의 n.n%만큼 상대 마법방어력의 일정 비율을 계산하여 별도 항목으로 표시
- 마법방어력 관통 보너스 = 상대 마법방어력 × (마법방어력 관통 해방 옵션% / 100)
- **마법공격력에 합산되지 않으며, 별도 항목으로 표시됨**

#### ■ 예시
- 상대 마법방어력: 800
- 마법방어력 관통 해방 옵션: 3.5%
- 마법방어력 관통 보너스 = 800 × (3.5 / 100) = 28
- 마법공격력: 400 (별도 표시)
- 마법방어력 관통 보너스: +28 (별도 표시)

---

### 5-3. 결과 표시

#### ■ 표시 항목
- 공격력 (관통 보너스 제외)
- 마법공격력 (관통 보너스 제외)
- 방어력 관통 보너스 (별도 항목, 값이 있는 경우만 표시)
- 마법방어력 관통 보너스 (별도 항목, 값이 있는 경우만 표시)
