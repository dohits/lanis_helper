# Lanis Helper 프로젝트 개요

## 📁 프로젝트 구조

### 핵심 모듈
- **src/content/index.js**: 메인 콘텐츠 스크립트
- **src/background/index.js**: 백그라운드 스크립트
- **src/popup/index.js**: 팝업 스크립트

### 메뉴 모듈 (src/content/menu-module/)
사용자 인터페이스와 모달 기능을 담당하는 모듈화된 구조
- **actions/**: 메뉴 액션 핸들러
- **events/**: 이벤트 처리
- **modal/**: 모달 컴포넌트들
- **renderers/**: UI 렌더링
- **state/**: 상태 관리
- **ui/**: UI 관리자

### DOM 모듈 (src/content/dom-modules/)
페이지 DOM을 직접 조작하는 기능들을 모듈화한 구조

#### 사용자 네비게이션 (user-navigation/)
사용자명 클릭으로 프로필 페이지 이동 기능
- **UserNavigationManager.js**: 메인 관리자
- **UsernameClickHandler.js**: 사용자명 클릭 기능
- **DynamicContentObserver.js**: 채팅 메시지 감지

#### 프로필 강화 (profile-enhancement/)
사용자 프로필 페이지에 추가 정보 표시 기능
- **ProfileEnhancementManager.js**: 메인 관리자
- **CombatPowerSticker.js**: 전투력 스티커
- **StatSumSticker.js**: 스탯합계 스티커
- **HpMpBonusSticker.js**: HP/MP 보너스 스티커
- **DynamicContentObserver.js**: 프로필 DOM 감지

#### 기타 DOM 모듈
- **search-engine/**: 검색 엔진 기능
- **item-stats/**: 아이템 스탯 기능
- **shared/**: 공통 유틸리티

### API 모듈 (src/api/)
구글 시트 API 연동 기능
- **googleSheetLoad/**: 구글 시트 데이터 로딩
  - **index.js**: 공통 API 모듈
  - **priceDataAPI.js**: 가격 데이터 API
  - **abilityInfoAPI.js**: 능력치 정보 API
  - **enchantInfoAPI.js**: 인챈트 정보 API

### 계산기 모듈 (src/content/calculator/)
기대값 계산기 및 관련 기능
- **expected-value-calculator.js**: 기대값 계산기
- **price-fetcher.js**: 가격 데이터 가져오기
- **item-configs.js**: 아이템 설정

## 🔧 주요 기능

### 1. 메뉴 시스템
- **모듈화된 메뉴 구조**: 각 기능별로 독립적인 모듈로 구성
- **모달 기반 UI**: 사용자 친화적인 모달 인터페이스
- **상태 관리**: 중앙화된 상태 관리 시스템

### 2. DOM 조작 기능

#### 사용자 네비게이션
- **사용자명 클릭**: 채팅에서 사용자명 클릭 시 프로필 페이지로 이동
- **동적 감지**: 새로운 채팅 메시지 자동 감지 및 처리

#### 프로필 강화
- **전투력 스티커**: 스탯 합계 + HP/MP 보너스 계산 및 표시
- **스탯합계 스티커**: 순수 스탯 점수 합계 표시
- **HP/MP 보너스 스티커**: HP/MP 점수 표시
- **동적 감지**: 프로필 페이지 DOM 자동 감지 및 스티커 적용

### 3. API 연동
- **구글 시트 연동**: 실시간 가격 데이터 로딩
- **다중 데이터 소스**: 기존/새로운 데이터 형식 지원
- **오류 처리**: 사용자 친화적인 오류 메시지

### 4. 계산기 기능
- **기대값 계산**: 아이템 강화 기대값 계산
- **가격 데이터**: 실시간 시세 정보
- **설정 관리**: 사용자 설정 저장/로드

## 🏗️ 아키텍처 특징

### 모듈화 설계
- **단일 책임 원칙**: 각 모듈은 하나의 명확한 책임을 가짐
- **기능별 분리**: 네비게이션과 정보 표시 기능을 완전히 분리
- **의존성 분리**: 모듈 간 느슨한 결합
- **재사용성**: 공통 기능의 재사용 가능한 구조

### 확장성
- **플러그인 방식**: 새로운 기능을 쉽게 추가 가능
- **설정 기반**: JSON 설정 파일로 동작 제어
- **이벤트 기반**: 모듈 간 이벤트 기반 통신

### 유지보수성
- **명확한 구조**: 폴더별 기능 분리
- **일관된 네이밍**: 통일된 파일/클래스 명명 규칙
- **문서화**: 각 모듈의 역할과 사용법 문서화
