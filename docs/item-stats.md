# 아이템 스탯 시스템

## 개요
라니스 게임의 아이템 스탯을 분석하고 등급을 표시하는 시스템입니다. 각 아이템의 위력과 무게를 기반으로 태그를 부여합니다.

## 장비 타입 분류

### 무기
- **키워드**: 창, 도끼, 검, 나이프, 지팡이, 너클, 활
- **DOM 선택자**: `p.MuiTypography-root.MuiTypography-body2.css-1xgulgv`

### 방어구
- **키워드**: 방어구
- **DOM 선택자**: `p.MuiTypography-root.MuiTypography-body2.css-1xgulgv`

### 장신구
- **키워드**: 장신구
- **DOM 선택자**: `p.MuiTypography-root.MuiTypography-body2.css-1xgulgv`

## 태그 시스템

### 1. 장비 태그 (최종 등급)

#### 표시 형식
```
[태그] 점수 (최소값~최대값) (퍼센트)
```

#### 계산 공식

| 장비 타입 | 계산 공식 |
|-----------|-----------|
| 무기/방어구 | `실제 위력 - 실제 무게 × 2` |
| 장신구 | `실제 위력 × 5.5 - 실제 무게 × 2` |

#### 범위 계산

| 장비 타입 | 최소값 | 최대값 |
|-----------|--------|--------|
| 무기/방어구 | `최소위력 - 최대무게 × 2` | `최대위력 - 최소무게 × 2` |
| 장신구 | `최소위력 × 5.5 - 최대무게 × 2` | `최대위력 × 5.5 - 최소무게 × 2` |

#### 퍼센트 계산
```
퍼센트 = ((현재값 - 최소값) / (최대값 - 최소값)) × 100
```

#### 등급 기준

| 퍼센트 | 태그 | 색상 |
|--------|------|------|
| 100% | [완전무결] | 무결 등급 색상 |
| 95% 이상 | [종결] | 최상 등급 색상 |
| 90% 이상 | [준종결] | 상 등급 색상 |
| 90% 미만 | 태그 없음 | - |

#### 색상 적용
- **태그 부분만** 색상 적용
- 점수, 범위, 퍼센트는 기본 색상 사용

## 폴백 시스템

### 데이터 부족 시
- 위력/무게 범위 데이터가 없는 경우 기존 점수 합산 방식 사용
- `currentPower`와 `currentWeight`가 있는 경우 새로운 계산 방식 적용
- 완전한 데이터가 없는 경우 기존 태그 조건 적용

### 기존 태그 조건 (폴백용)

#### 일반 장비 (위력/무게 모두 정상)
- 16점: [완전무결]
- 12-15점: [종결]
- 11점: [준종결]

#### 위력만 좁은 범위
- 8점 + 무게 무결: [완전무결]
- 6-7점: [종결]
- 5점: [준종결]

#### 무게만 좁은 범위
- 8점 + 위력 무결: [완전무결]
- 6-7점: [종결]
- 5점: [준종결]

## 기술적 특징

### 장비 타입 감지
- 아이템 이름의 키워드 기반 분류
- DOM 선택자를 통한 정확한 위치 파악
- 폴백 메커니즘으로 안정성 확보

### 계산 정확도
- 부동소수점 연산 정밀도 보장
- 퍼센트 계산 시 `Number.EPSILON` 사용
- 범위 검증으로 0-100% 제한

### 성능 최적화
- 캐싱을 통한 중복 계산 방지
- 조건부 렌더링으로 불필요한 DOM 조작 최소화
- 메모리 효율적인 이벤트 처리
