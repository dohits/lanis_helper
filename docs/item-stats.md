# 아이템 스탯 시스템

## 개요
라니스 게임의 아이템 스탯을 분석하고 등급을 표시하는 시스템입니다. 각 아이템의 위력과 무게를 기반으로 태그를 부여합니다.

## 장비 타입 분류

### 무기
- **키워드**: 창, 도끼, 검, 나이프, 지팡이, 너클, 활
- **DOM 선택자**: `p.MuiTypography-root.MuiTypography-body2.css-1xgulgv`

### 방어구
- **키워드**: 방어구
- **DOM 선택자**: `p.MuiTypography-root.MuiTypography-body2.css-1xgulgv`

### 장신구
- **키워드**: 장신구
- **DOM 선택자**: `p.MuiTypography-root.MuiTypography-body2.css-1xgulgv`

## 계산 공식

### 장비별 점수 계산

| 장비 타입 | 계산 공식 |
|-----------|-----------|
| 무기/방어구 | `실제 위력 - 실제 무게 × 2` |
| 장신구 | `실제 위력 × 5.5 - 실제 무게 × 2` |

### 범위 계산

| 장비 타입 | 최소값 | 최대값 |
|-----------|--------|--------|
| 무기/방어구 | `최소위력 - 최대무게 × 2` | `최대위력 - 최소무게 × 2` |
| 장신구 | `최소위력 × 5.5 - 최대무게 × 2` | `최대위력 × 5.5 - 최소무게 × 2` |

### 퍼센트 계산
```
퍼센트 = ((현재값 - 최소값) / (최대값 - 최소값)) × 100
```

## 아이템 등급분류 조건

| 등급 | 위력 기준 | 무게 기준 | 색상 |
|------|-----------|-----------|------|
| 무결 | 100.0% (최대값) | 100.0% (최소값) | #00FFF0 |
| 완벽 | 95.0% ~ 99.9% | 95.0% ~ 99.9% | #FFE066 |
| 최상 | 90.0% ~ 94.9% | 90.0% ~ 94.9% | #FF5555 |
| 상 | 70.0% ~ 89.9% | 70.0% ~ 89.9% | #C770FF |
| 중 | 50.0% ~ 69.9% | 50.0% ~ 69.9% | #FFFF66 |
| 하 | 30.0% ~ 49.9% | 30.0% ~ 49.9% | #66A3FF |
| 최하 | 5.01% ~ 29.99% | 5.01% ~ 29.99% | #CCCCCC |
| 불량 | 0.01% ~ 5.00% | 0.01% ~ 5.00% | #BBBBBB |
| 폐급 | 0% (최소값) | 0% (최대값) | #888888 |

> **참고**: 
> - 위력은 높을수록 좋음, 무게는 낮을수록 좋음
> - 범위가 0인 경우(최소값=최대값)는 무결 또는 누락만 판정
> - 현재값이 범위를 벗어나면 '누락' 등급으로 표시
> - **폐급**은 오직 "정확히 최소값(0%)"만 해당하며, 0.01%부터는 불량 등급입니다.

## 아이템 태그 조건 (새로운 로직)

| 태그 | 조건 | 퍼센트 기준 | 색상 |
|------|------|-------------|------|
| 완전무결 | 장비별 계산 점수 100% | 100% | #00FFF0 |
| 종결 | 장비별 계산 점수 95% 이상 | 95% 이상 | #FF5555 |
| 준종결 | 장비별 계산 점수 90% 이상 | 90% 이상 | #C770FF |

## 표시 형식

### 장비 태그
```
[태그] 점수 (최소값~최대값) (퍼센트)
```

### 위력/무게 표시
```
값 (범위) [등급] (퍼센트)
```

## 색상 적용 규칙

### 장비 태그
- **태그와 퍼센트만** 색상 적용
- 점수와 범위는 기본 색상 사용

### 위력/무게 표시
- **등급과 퍼센트만** 색상 적용
- 값과 범위는 기본 색상 사용

## 적용 위치

### DOM 모듈
- **파일**: `src/content/dom-modules/item-stats/`
- **적용 위치**: 인벤토리, 아이템 상세 페이지
- **주요 클래스**: `FinalTagAdder`, `RangeInfoAdder`

### 모달 시스템
- **파일**: `src/content/menu-module/modal/calculator/equipment-enchant-sim-modal/`
- **적용 위치**: 장비 감정 시뮬레이션 모달
- **탭**: 장비 뽑기, 감정 순위, 점수표
- **점수표 기능**:
  - 컬럼 토글 기능 (장비명 제외)
  - 모바일 최적화 (8px 글자 크기)
  - 반응형 테이블 디자인

## 기술적 특징

### 장비 타입 감지
- 아이템 이름의 키워드 기반 분류
- DOM 선택자를 통한 정확한 위치 파악
- 폴백 메커니즘으로 안정성 확보

### 계산 정확도
- 부동소수점 연산 정밀도 보장
- 퍼센트 계산 시 `Number.EPSILON` 사용
- 범위 검증으로 0-100% 제한

### 성능 최적화
- 캐싱을 통한 중복 계산 방지
- 조건부 렌더링으로 불필요한 DOM 조작 최소화
- 메모리 효율적인 이벤트 처리
