# Lanis Helper - 크롬 확장프로그램

Lanis 사용자 경험을 향상시키는 크롬 확장프로그램입니다.

## 🚀 설치 방법

### PC (Chrome 브라우저)

1. 이 프로젝트를 다운로드 합니다. (lanis_helper.zip 제외)
2. Chrome 브라우저에서 `chrome://extensions/` 접속
3. 우측 상단의 "개발자 모드" 활성화
4. "압축해제된 확장 프로그램을 로드합니다" 클릭
5. 프로젝트 폴더 선택

### 모바일 (Android)

1. lanis_helper.zip 파일을 다운.
2. 플레이 스토어에서 Mises 브라우저 다운로드
3. 하단바에서 퍼즐모양 아이콘 클릭 -> 확장 프로그램 선택
4. 페이지에서 개발자모드 활성화
5. +(from .zip/.crx/.user.js) 항목 선택
6. 다운받은 zip 파일 불러오기

## ✨ 주요 기능

### 사용자 프로필 링크
- 채팅에서 사용자 이름을 클릭하면 해당 사용자의 프로필 페이지로 이동
- 자동으로 사용자 이름을 감지하여 클릭 가능하게 만듦

### 아이템 감정범위 표기
- Lanis 위키에서 레어 아이템 정보를 자동으로 수집

## ⚙️ 설정 방법

아래와 같이 확장프로그램 아이콘을 클릭하면 설정창이 나타납니다.

![설정창 예시](img/popup_example.jpg)

- **사용자 프로필 링크**: 채팅에서 사용자 이름을 클릭하면 해당 사용자의 프로필 페이지로 이동합니다.
- **감정 범위 표기**: 아이템 감정 범위 및 등급(최하~최상, 종결/준종결)을 표시합니다.
- **기능 2, 기능 3**: 추후 추가될 기능입니다.
- **레어 아이템 데이터 수집**: Lanis wiki에서 레어 아이템 정보를 자동으로 수집합니다.
- 하단에 상태 메시지가 표시됩니다(예: "대기 중...").

토글 스위치를 클릭하여 각 기능을 켜거나 끌 수 있으며, 설정은 즉시 저장되고 적용됩니다.

## 📝 사용법

### 사용자 프로필 링크 사용
- Lanis 채팅 페이지에서 사용자 이름을 클릭하면 자동으로 프로필 페이지로 이동합니다

### 레어 아이템 데이터 수집
1. Lanis 위키 레어 아이템 페이지 접속
2. 확장프로그램 아이콘 클릭
3. "레어 아이템 데이터 수집" 버튼 클릭
4. 수집 완료까지 대기
